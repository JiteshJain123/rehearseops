What the model can and can't influence

  • Model output is untrusted input. Actions must match a strict grammar. Unknown types, extra parameters and out-of-range values are denied.
  • Facts need a source. A value pulled from logs must appear in the line it cites, and still needs your confirmation.
  • Logs can't give orders. Log lines and web snippets are passed as data. The live injection test checks this.
  • Keys stay on the server. The browser never sees them, and an hourly budget caps model spend on a public demo.

About RehearseOps

NVIDIA Nemotron, running on Nebius Token Factory, investigates an incident and proposes typed recovery actions. A deterministic gate checks each one against confirmed facts and sends any violation back for the model to revise. Only approved actions are rehearsed.

"Approved" means approved for rehearsal, not for production. This app cannot change real infrastructure. The bundled incidents are synthetic; you can also bring your own logs.
